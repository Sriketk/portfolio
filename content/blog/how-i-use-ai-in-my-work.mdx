Reverse chronological. Newest first.

## Superset + Zed

Regular Claude Code inside a GUI for managing worktrees, then Zed to look at and edit files. 

## cmux

Terminal support in the other tools was bad. Needed something on Ghostty. Used this with Cursor for file editing and viewing.

## Claude Code + Cursor

Not a big fan of the Claude Code UX, but needed the usage rates. Used Cursor to look at edited files. Reading text in Claude Code is still a pain. Computer would often run out of memory.

## 2025 — Conductor

Very innovative with the worktrees implementation. Managing worktrees yourself is too confusing if you decide you want manual control. The actual AI chat was not the best and often very slow.

## 2024 — Cursor

Plain ol' Cursor.
